# Maestro's Pickleball Club – Open Play Queue

Single-file web app (no build step, no dependencies). Open `index.html` in a browser, or host it free with GitHub Pages.

## Features
- Saved players, editable courts, Singles/Doubles matches
- Fair queue: fewest games first, rotating tie-breaker
- Session ranking (only players who played this session)
- Light / dark mode, responsive
- Data saved in the browser; Export / Import backup (.json)

## Deploy with GitHub Pages
1. Create a repository and upload `index.html` and this README.
2. Settings > Pages > Source: **Deploy from a branch**, Branch: **main** / **(root)**.
3. Open the URL GitHub shows (https://YOUR-NAME.github.io/REPO-NAME/).

Data is stored per browser and device, so use Export backup to move it.
